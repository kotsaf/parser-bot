# Бот для управления источниками парсинга

Этот телеграм-бот позволяет добавлять новые источники для парсинга через загрузку Excel-файлов.

## Как развернуть

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd <repository-name>
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Создайте бота в Telegram и замените токен в конце файла bot,py

## Запуск

```bash
python bot.py
```

## Использование

1. Запустите бота командой `/start`
2. Подготовьте Excel-файл со следующими колонками:
   - `title`: название сайта
   - `url`: ссылка на сайт
   - `xpath`: путь к элементу с ценой
3. Отправьте файл боту
4. Бот сохранит данные в базу и покажет содержимое файла

## Структура проекта

- `bot.py` - основной файл бота
- `requirements.txt` - зависимости проекта
- `sources.db` - база данных SQLite
- `README.md` - документация
